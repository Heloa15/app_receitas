# Livro de Receitas

## Sobre o projeto

O Livro de Receitas é um aplicativo desenvolvido em Flutter e Dart que permite cadastrar, visualizar, editar, excluir e favoritar receitas culinárias. O objetivo é facilitar a organização de receitas em um único lugar, com uma interface simples e intuitiva.

## Funcionalidades

- Cadastro de receitas.
- Visualização dos detalhes das receitas.
- Edição de receitas cadastradas.
- Exclusão de receitas.
- Marcação de receitas favoritas.
- Exibição de ingredientes.
- Modo de preparo detalhado.
- Exibição do custo aproximado das receitas.
- Exibição de imagens das receitas.

## Tecnologias utilizadas

- Flutter
- Dart
- Material Design

## Estrutura do projeto

- `lib/models/receitas.dart`: modelo de dados das receitas.
- `lib/screens/detalhes.dart`: tela de detalhes das receitas.
- `lib/screens/novareceita.dart`: tela de cadastro e edição de receitas.
- `lib/theme/theme.dart`: configuração do tema visual.
- `lib/main.dart`: arquivo principal do aplicativo.
